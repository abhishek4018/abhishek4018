    ### 🚀 Featured Project: [NeoFlow-QA](https://github.com/abhishek4018/NeoFlow-QA)                                                                                                                                                     
                                                                                                                                                                                                                                          
    **NeoFlow-QA** is an **Agentic BDD Test Automation Engine** built on **Serenity/JS 3.x**, **Cucumber.js**, **Playwright**, and **TypeScript**, powered by an autonomous 4-stage AI agent (`neo`).                                     
                                                                                                                                                                                                                                          
    #### 💡 Highlights & Capabilities:                                                                                                                                                                                                    
    - 🎭 **Screenplay Pattern over POM**: Decouples Actors, Tasks, and Targets for maintainable, human-readable test steps.                                                                                                               
    - 🤖 **Autonomous AI Agent (`neo`)**:                                                                                                                                                                                                 
      1. *Playwright Codegen Recording* (`codegen/*_raw.spec.ts`)                                                                                                                                                                         
      2. *Replay Gate Verification*                                                                                                                                                                                                       
      3. *Gherkin BDD & Serenity Step Definition Generation*                                                                                                                                                                              
      4. *Living BDD HTML Report Compilation*                                                                                                                                                                                             
    - 🌐 **Cross-Browser & Cloud Grid Support**: Executes across Chromium, Firefox, WebKit, and cloud grids like LambdaTest (`USE_LAMBDATEST=true`).                                                                                      
    - 🎯 **Shift-Left Accessibility Locators**: Built-in explicit `#id`, `data-testid`, and WCAG `aria-label` locators eliminate element ambiguity.                                                                                       
    - 📊 **Living BDD HTML Reports**: Generates executive-ready reports with step-by-step screenshot trajectories.
